## Command Library and Customization: Beyond the Defaults

HARPA AI comes with over 100 pre-built commands, but what makes the tool genuinely flexible is the ability to customize these commands or create entirely new ones tailored to your specific workflow.

The pre-built command library covers major categories of work. The writing section includes commands for expanding bullet points into paragraphs, rewriting text in different tones, generating blog outlines, creating social media posts, and drafting various types of content. Marketing commands focus on SEO keyword research, competitor analysis, content strategy development, and audience segmentation. Email commands handle drafting replies, summarizing threads, and generating responses that match conversation context.

Research commands are particularly useful—they can extract data from web pages, summarize academic papers, create study guides, and organize information from multiple sources. The web automation section contains commands for form filling, data scraping, price monitoring, and website tracking. Language learning commands help with grammar explanations, vocabulary building, and creating customized lesson plans.

But here's where things get interesting: you can edit any of these pre-built commands to better match your needs. Each command is essentially a sequence of steps written in a format HARPA understands. You can modify the prompts, adjust parameters, change how data gets processed, or alter the output format.

Creating custom commands opens up even more possibilities. You can build automation workflows that navigate to specific websites, extract particular pieces of information, process that data through AI models with custom prompts, and then export or display results in exactly the format you need. These custom automations can be scheduled to run at specific times or triggered by certain events.

HARPA uses a system of parameters to make commands flexible. Parameters like {{page}} reference the current page content, {{transcript}} extracts YouTube video transcripts, {{selection}} grabs text you've highlighted, and {{gpt}} references the last AI response to chain multiple requests together. You can create custom parameters like {{p1}} or {{p2}} to store data or options that get reused throughout a command sequence.

Global parameters such as {{g.tone}} let you set preferences that apply across all your commands. For example, you might set a global tone parameter to "professional but friendly," and any command that generates written content will automatically apply that tone unless you override it specifically.

The chunking feature deserves mention because it solves a real technical limitation. Large language models have token limits—ChatGPT can only process about 8,000 tokens at once, for instance. When you need to analyze a 50-page document or a two-hour YouTube transcript, chunking automatically divides the content into smaller pieces, processes each chunk through the AI model, and then combines the results. You can configure how chunking works to maintain context across chunks if needed.

Team spaces are available on S plans, allowing multiple people to share custom commands across an organization. This is useful for businesses that want to standardize certain workflows or automations across team members. Commands created in a shared space are accessible to all members, and updates propagate automatically.

The command editor itself uses a visual interface where you can drag and drop steps, configure parameters, test outputs, and debug issues. You don't need to write code, but if you're technically inclined, you can dive into the underlying structure for more precise control.

## Limitations and Considerations: What HARPA AI Doesn't Do Well

No tool is perfect for everyone, and HARPA AI has limitations worth understanding before you commit time and money to integrating it into your workflow.
